## 验收分层

- L0：单元、wire、并发、fuzz、确定性测试。
- L1：特权 FRR/VPP 控制面及 FIB 编程。
- L2：QEMU/Docker 报文级转发和恢复。
- L3：真实 PCI/VFIO/uio、DPDK 性能和多流分布。

当前 L0/L1 已基本完成，L2 已完成 e1000 与 VMware VMXNET3 polling-only 双端口可达性，L3 受宿主环境
限制；任何 L3 项不得由 QEMU 结果替代。

## 后续执行顺序

1. 固化并版本化 Route/NH/NHGroup contract 与删除/回滚/replay conformance。
2. 增加 FRR、DANOS、VPP 分别重启、zserv 断连、ECMP 路径上下线验收。
3. 固化 QEMU e1000 功能 lane，增加 VMXNET3 和真实 PCI DPDK preflight/perf lane。
4. 建立 PPS、吞吐、延迟、CPU、ECMP bucket 分布和长稳测试基线。
5. 仅在上述基线稳定后进入 BFD、VLAN、VXLAN、EVPN 扩展。
